# opdrachtGIT
lesson github e github desktop

Maak online een nieuwe repo aan: opdrachtGIT.

Clone deze naar je harde schijf.

Plaats een drietal van de oefeningen of opdrachten uit de vorige hoofdstukken in de lokale map opdrachtGIT.

Zorg dat deze zowel lokaal als online in de repos komen.

Maak een schermafdruk van de geopende repo online zodat zowel de url, repo naam als de bestanden zichtbaar zijn.

Stuur deze schermafdruk in.
